WHY THIS WORKS:
• Port 6543 = Supabase Connection Pooler (pgBouncer) ❌
  - Faster but doesn't support prepared statements
  - Causes "prepared statement does not exist" error

• Port 5432 = Direct Database Connection ✅
  - Fully compatible with Prisma
  - Slightly slower but works perfectly

NEED HELP FINDING YOUR .env FILE?
If you don't have a .env file, create one in e:\nextjs\ with:

DATABASE_URL="your-supabase-connection-string-here"
JWT_SECRET="your-secret-key"

Get your connection string from:
Supabase Dashboard → Project Settings → Database → Connection string
Choose "Session mode" (port 5432)
